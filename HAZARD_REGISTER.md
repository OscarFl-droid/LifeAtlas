# Phase 1 Hazard Register

| Hazard | Control |
|---|---|
| Browser storage loss | IndexedDB, persistent-storage request, participant backup/export workflow, restore test |
| Forgotten passphrase | Explicit warning; passphrase is not recoverable |
| Overconfident inference | Minimum evidence gates, alternatives, confidence labels, low-risk experiments only |
| Clinical interpretation | Prohibited output policy and non-clinical wording |
| Excessive burden | Short forms, one substantive suggestion/day, no streak punishment |
| Sensitive data leakage | Local processing, encrypted voluntary export, no analytics or server account |
| Native-source overclaim | Manual fallback and explicit bridge status |
| Model error | Inspectable evidence, participant contestation planned, deterministic replay |
| Cross-person misuse | Within-person exploratory analysis; no ranking or normative score |
